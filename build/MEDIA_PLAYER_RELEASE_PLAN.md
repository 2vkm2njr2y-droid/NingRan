# 凝然媒体播放器 6.1.15 发布计划

## 目标

本次发布提供两个互不依赖的 Windows x64 安装包：

1. `凝然加密-6.1.15-安装程序.exe`：安装凝然加密、安全组件和内置查看所需组件，但不安装独立播放器程序。
2. `凝然媒体播放器-6.1.15-安装程序.exe`：只安装独立播放器及其解码组件。

## 使用方式

1. 单独安装凝然媒体播放器时，用户可通过程序内的“打开文件”选择现有代码定义的音频、视频文件播放；安装时默认勾选并注册全部 19 种已支持格式的文件关联。
2. 同时安装凝然加密和播放器时，凝然加密的安全查看会启动已安装的播放器，并通过受控读取通道提供已验证的加密媒体内容；不会写出临时明文媒体文件。该通道只由本次启动的播放器进程连接，且不传输密码、密匙、数据密钥或临时口令。
3. 只安装凝然加密时，安全查看维持现有内置播放器回退路径，不显示“未安装播放器”错误。
4. 播放器安装包使用播放器专用的安装说明和卸载说明。Windows 可能保留用户已有的默认播放器；播放器仍会注册为全部已支持格式的可用打开方式。

## 实施和验证

1. 将播放器从浏览器播放控件改为随包携带的 LibVLC 解码核心，并保留普通文件与安全查看两种入口。
2. 让安装程序在构建时根据产品类型选择名称、默认安装目录、可执行文件、卸载项、快捷方式名称和产品专用说明。
3. 发布主程序时排除独立播放器文件；发布播放器时保留 `libvlc` 与 `plugins` 目录。
4. 对播放器运行安全通信自检，检查 19 种文件关联的注册清单，并分别验证两个安装包的内嵌文件清单与 SHA-256 校验文件。
