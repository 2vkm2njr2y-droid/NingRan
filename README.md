# 凝然加密

**中文** | [English](README_EN.md)

凝然加密是一款面向 Windows x64 的本地文件保护程序。文件加密、解密、身份管理和设备核验均在本机完成，程序不会主动上传文件、密码、密匙或身份数据。

> 当前构建版本：**10.0.3**。Windows x64 安装包生成在仓库的 `dist` 目录中。

## 主要功能

- 加密和解密文件或文件夹。
- “安全交付”可把多个文件和文件夹放入一个 `.nrenc` 交付包，并设置有效期、接收联系人和是否允许导出。
- 支持密码、密码加密匙文件、密码加物理设备三种旧版保护方式；新建文件还支持自定义组合保护。
- 自定义组合保护可以同时要求密码、密匙文件、可持续检测的移动存储密匙和 Windows Hello；勾选的条件必须全部满足。物理密匙规则支持至少需要几把和禁止插入名单，解锁后持续检查，插入禁止密匙或失去必要条件会立即取消当前会话。
- 新建固定容量保险箱时可选择双层隐蔽空间；两套不同密码从同一入口打开各自独立内容。
- 解锁后可在程序内浏览加密文件树；常见文本、图片、音频和视频按需分段读取，不在磁盘留下明文。
- 内嵌安全媒体播放器支持文件列表、全屏、左右方向键快进或后退、单击或拖动进度条跳转，以及进度条悬停预览。
- 普通文件可按需导出或完整还原；图片支持缩放和滚动切换，音视频支持播放列表与结束后播放规则。
- 支持创建、备份和恢复私密身份。
- 支持分享公开身份，并通过大小写敏感的 7 位安全码确认联系人。
- 解锁前隐藏保护方式、原始名称、内部目录、发送者和设备信息。
- 同一 Windows 用户只打开一个主窗口；再次双击程序或关联文件时，由已有窗口接收新文件。
- 严格防护使用单独的管理员监控程序，定期检查主窗口、内嵌播放器、预览画面和监控程序自身，并在发现可疑读取后停止操作和清理临时内容。

## 常见文件类型

- `.jpg`：7.0 起在 NTFS 磁盘上生成的凝然加密照片。文件本身是普通 JPEG，普通看图软件只显示用户选择的封面；加密内容保存在同名文件的 NTFS 隐藏数据流中。
- `.nrenc`：可移动的凝然加密包，也是非 NTFS 磁盘的默认输出格式；10.0.3 继续兼容读取 8.0.1、8.0.2、8.0.5 及原有 6.1 格式的 `.nrenc`。对普通（非安全交付）加密包追加或删除内容时，新版本会把修改作为加密尾部分段追加，不再按完整文件制作临时副本；删除先记入最新目录，因此磁盘空间不足时不会因为需要再放下一份完整加密包而失败。
- `.nrkey`：程序生成的专用密匙文件。

### 自定义组合保护和 Windows Hello

新格式使用独立的 `NRARC009` 文件头，旧版加密文件仍按原规则读取，不会被自动改写。创建时可以选择密码、密匙文件、物理密匙和 Windows Hello 的任意组合；勾选的每一项都必须通过。密匙文件可以单独使用，也可以和其他条件一起使用。物理密匙可以设定至少需要插入的数量，并列出禁止插入的已登记移动存储；插入禁止设备会直接拒绝解锁。解锁后程序持续检查授权设备，规则不再满足时会取消当前查看或写入操作。

Windows Hello 的凭据绑定登记时的本机和当前 Windows 账户，只能在该本机账户上解锁。支持 HMAC-secret/PRF 的配置会直接使用 Hello 派生的离线密钥；部分 Windows Hello 配置不提供该扩展时，程序会改用仍要求 PIN/生物识别验证、并用当前 Windows 账户保护的本机恢复资料。Windows Hello 重置、删除登录配置、重装系统、切换账户或更换电脑后，Hello 条件可能无法恢复；因此使用 Hello 时应同时保留密码或密匙文件恢复条件。程序不会保存 Hello 的 PIN、人脸或指纹数据，也不会把这些数据写入保险箱。
- `.nrid`：加密的私密身份备份。
- `.nrpub`：可以分享的公开身份。

## 隐私与安全设计

- 加密文件可以自由改名，不影响正常解密。
- 原文件的完整路径不会写入加密文件。
- 保护方式、发送者身份、原文件名和内部目录等信息在成功解锁前不会显示。
- 物理设备的名称、型号、容量和原始编号不会以明文保存在加密文件中。
- 普通文件被用作密匙时只会被读取，不会被修改或转换。
- 8.0.2 保存到 NTFS 时，主 `.jpg` 只保留未经改动的普通封面照片，加密内容存放在其隐藏数据流中；旧版 `.nrenc` 继续兼容。

移动 `.jpg` 时，只有在 NTFS 磁盘之间使用 Windows 正常移动或复制，隐藏数据流才会保留。复制到 FAT、exFAT 等其他磁盘、部分云盘同步目录或某些压缩工具时，隐藏数据流可能丢失，照片仍能正常显示但无法再打开加密内容。跨磁盘携带、上传或发送前，请在凝然的“导出”中选择“导出加密包（.nrenc）”。

## 安全交付

点击主窗口右上角“安全交付”，可同时添加多个文件和多个顶层文件夹。向导会保留子目录、空目录、空文件以及中文、英文、空格和常见符号名称；填写交付说明并设置密码、有效期和导出规则后，程序先检查资料、保存位置与磁盘空间，再生成 `.nrenc` 并重新读取、完整验证。取消或失败不会修改原始资料。

接收方必须安装凝然，并完成密码及发送者验证后才能看到交付信息和文件树。禁止导出时，单文件、文件夹和全部明文导出都会在界面和加密读取层同时拒绝，但有效期内仍能在凝然中安全查看支持的内容。到期后仍显示交付名称、说明、发送者、指定接收者和文件树，但文字、图片、PDF、音频、视频与所有明文导出立即停止，已经建立的读取会话也会结束。

有效期依赖接收方电脑的本地时间，离线软件无法完全阻止故意修改系统时间。禁止导出只能限制凝然提供的普通入口，无法阻止截图、拍照或录屏。凝然不会上传或发送交付包；用户通过 U 盘、邮件、聊天软件或网盘发送时，外部平台可能保留副本、文件名或传输记录。请通过与交付包不同的安全方式单独告知密码。

## 固定容量保险箱

新建保险箱可选择 1 GB、5 GB、20 GB、50 GB 或自定义固定容量。未使用区域会写入随机数据，加入、修改或删除资料不会改变保险箱单文件的总大小。新版保险箱直接读取加密目录和所需数据块，不会在打开、修改小文件或锁定时整体解包、重新打包。创建固定容量本身需要实际写满所选大小，因此耗时和磁盘写入量会随总容量增加，并可在界面中查看进度和取消。

创建时可打开默认关闭的“建立隐蔽空间”，为同一个保险箱设置两套明显不同的密码和两块固定容量区域。输入日常密码只显示日常内容，输入秘密密码只显示另一套内容；两者使用不同的数据钥匙和加密目录，并从同一个“打开保险箱”入口解锁。任一密码打开后都会优先挂载为 Windows 临时磁盘并自动打开资源管理器；挂载失败时才提供凝然内部查看作为备用方式。固定总容量和两块区域创建后不能调整，忘记任一密码都无法恢复对应内容。

“隐蔽”表示减少日常界面、目录和普通记录中的直接暴露，不代表绝对无法发现。长期比较保险箱副本、键盘或屏幕监控、内存取证，以及导出明文后由 Windows、外部软件、搜索、缩略图、杀毒软件或云同步留下的记录，都可能暴露使用情况。

现有旧保险箱仍可打开。程序查看旧单文件保险箱的基本信息时只读取内部识别信息，不再为此整体解包。选择“升级旧保险箱”可另存为新版固定容量保险箱；程序逐个搬移加密分段，不在磁盘还原整份明文，并在重新读取和完整检查后才报告成功。原保险箱不会被覆盖或删除，在自行确认新版内容前请继续保留原文件。

## 安全查看与媒体

在凝然中选择加密照片或 `.nrenc` 并解锁后，程序默认只显示其中的加密文件树，不会自动导出明文。双击文本、图片、音频或视频会在程序内打开；同一文件夹内的媒体可按类型筛选。普通文件双击后由用户选择导出位置；点击“导出”可选择导出加密包 `.nrenc` 或导出明文。保险箱导出 `.nrenc` 会直接读取已解锁空间，不依赖临时磁盘；即使临时磁盘挂载失败、改用软件内部查看，仍可导出。导出界面会显示压缩分析、加密写入和完整验证的总百分比，并在当前阶段运行数秒后显示速度与预计剩余时间；保险箱导出在完整验证通过后不再执行只用于原文件删除保护的额外整包读取。导出进行时不会因连续 15 分钟无人操作而中断；导出结束后会立即恢复检查，若此时已经超时便自动锁定。Windows 锁屏、注销、休眠、授权设备拔出、手动锁定和取消导出仍会立即终止导出。凝然不会关联 `.jpg`，因此在系统中普通双击仍由照片查看器打开封面。

主窗口右上角的“播放器设置”可以决定普通加密文件和安全交付包中的内容由凝然播放器、内置播放器还是 Windows 默认程序打开，选择会保存在本机并在下次启动时继续使用；默认使用凝然播放器。选择凝然播放器时，程序会优先识别安装在 `C:\Program Files\Mier\Media-Helper` 的播放器，并继续兼容旧的 `C:\Program Files\media-helper` 位置。播放器缺失或安全连接失败时会说明原因并停止，不会自动改用其他查看方式。选择“使用默认程序打开”后，双击任何普通文件会先解压到临时目录并交给 Windows 默认程序，凝然关闭时清理临时文件；如果文件大小或哈希发生变化，关闭时会再次要求加密文件密码和身份密码，并把修改后的文件替换回原加密包。默认程序打开失败时会提示原因并停止，不会继续使用凝然查看器。严格防护开启时会先提示是否允许外部程序读取临时明文，高安全查看仍只允许在凝然内查看。该选择不影响保险箱的备用查看窗口。勾选“读取子文件夹”会列出当前文件夹以下所有层级的媒体；取消勾选则只列出当前一层。选择凝然播放器或内置播放器时，媒体仍通过加密会话按需读取，不会因此导出明文文件。

安全查看时，凝然会独占锁定加密文件；若文件已经被其他程序占用，将拒绝打开。媒体预览直接在程序内部的小型播放画面中生成，只保留在内存中；如果两秒内无法取得画面，会明确提示“预览暂不可用”，不会无限等待。

可以在右上角设置“严格防护”。设置保存在只有管理员可修改的 Windows 区域；监控程序会单独请求管理员确认，并定期检查其他软件是否仍持有主窗口、内嵌播放器、预览画面或监控程序的内存读取权限。发现时，它会记录时间、访问程序、被访问组件和处理结果，停止当前操作、清理临时内容，再向用户提示。为防止恶意程序借合法外壳绕过检查，6.1.12 起不再提供自定义或自动允许名单。严格防护运行时，音视频改用受监控主进程内的播放器，PDF 暂停打开；开启防护前已经启动的外部查看器会先关闭。日志不记录视频画面、文件内容、密码或密匙，并可由用户导出。

严格防护是“发现和清理”措施，不是保证拦截的安全边界。一次很短的读取可能在下次检查前结束，因此严格防护不能保证阻止它。处理特别敏感的内容时，可选择“高安全打开（管理员确认）”。它会启动独立的管理员查看窗口，不会传递普通窗口中输入的密码或密匙，且要求重新验证；该窗口只允许查看文字和常见图片，不加载浏览器或第三方播放插件，因此不打开音频、视频和 PDF，也不允许导出、删除或修改内容。这个模式减少普通窗口中保留解锁材料的时间，但不是 Windows 最高级受保护进程：同一 Windows 账户下、已能读取其他程序内存的软件，仍可能超出程序控制范围。管理员或更高权限的软件、截图功能，以及同样已获得管理员权限的恶意软件也不在其保护范围内。

程序会检查 Windows 是否提供虚拟化安全区能力。密码和安全查看期间的数据密钥会尝试使用锁定内存，并在使用后立即清除；Windows 可能因系统资源或权限限制而无法锁定某一块内存。在不支持该 Windows 能力的电脑上，原有加密和安全查看仍可使用，程序会明确显示限制。普通桌面程序不能自行把整个查看窗口变成 Windows 的最高级受保护进程或安全区，因此不要把这一状态视为绝对防护。

请只在确有需要时使用严格防护或高安全打开，并保持 Windows、杀毒软件和备份处于正常状态。

## 无损压缩与媒体使用

加密界面提供“存储、最快、标准、完整”四个压缩等级。标准模式会跳过 MP4、MP3、JPG、压缩包等通常已经压缩的文件；完整模式会对所有文件尝试压缩。程序使用 Zstandard 进行无损压缩，并逐段比较压缩结果和原始数据，最终只保存较小的一份，不会降低图片、音频或视频质量。追加前会显示体积范围并检查内容完全相同的文件；加密或追加完成后会显示准确的体积报告。

解锁媒体后，播放器仍收到原始媒体字节，外部媒体传输逻辑保持不变。预览图、拖动、从 0:00 跳到 30:00 和播放速度调整按需读取所需片段，但实际响应还取决于视频关键帧、媒体编码、磁盘速度和电脑性能。程序不保证所有媒体编码格式都能播放。

安装包首页可以选择中文或 English；选择的语言会保存到安装目录，帮助窗口会使用对应语言。独立的“凝然媒体播放器”不随凝然加密安装包一起安装，Media-Helper 联动通道无需升级。

密码、密匙文件、私密身份备份和授权设备应分开保管。身份密码或必要的解锁材料遗失后，程序无法代为恢复。

可信联系人记录保存在普通程序不能修改的受保护位置。新增、删除或重新确认联系人时会出现 Windows 管理员确认；从 6.1.11 或更早版本保留下来的联系人不会被静默信任，必须重新核对安全码。FIDO2 安全密钥必须支持 PIN 或生物识别，程序不会退回到仅触摸确认。

## 安装

Windows x64 安装包可通过下方发布命令生成。安装时会正常升级已安装的旧程序，请先完全关闭凝然加密；`dist` 中不同版本号的旧安装包会继续保留。

## 源码目录

```text
src/
  NingRan.Core/        加密、身份和设备相关的核心功能
  NingRan.Windows/     Windows 桌面程序
  NingRan.MediaPlayer/ 独立媒体播放器组件
  NingRan.StrictMonitor/ 严格防护监控程序
  NingRan.Setup.Core/  安装与系统接入的核心功能
  NingRan.Setup/       Windows 安装程序源码
```

## 编译和运行

需要：

- Windows x64
- .NET 10 SDK
- PowerShell 或 Windows 终端

下载源码后，在项目根目录运行：

```powershell
dotnet restore NingRan.sln --locked-mode
dotnet build NingRan.sln -c Release
dotnet run --project src/NingRan.Windows/NingRan.Windows.csproj -c Release
```

如需体验程序，可在编译完成后直接运行桌面项目；普通用户建议使用发布页中的安装包。

制作 Windows x64、自带运行环境的单个 EXE 安装包：

```powershell
powershell -ExecutionPolicy Bypass -File build/Build-Release.ps1
```

成品和 SHA-256 校验值会写入 `dist`，文件名包含版本号，生成新版时不会删除旧版本安装包。未提供代码签名证书时，Windows 会把安装包显示为“未知发布者”。

双层保险箱在真实移动盘、完全断网环境和可控断电设备上的发布验收，使用：

```powershell
.\build\Invoke-DualVaultHardwareAcceptance.ps1 -Scenario Removable -Action Prepare -TestRoot F:\
```

完整的准备、拔盘/断电、重启后核验步骤和通过标准见 [HARDWARE_ACCEPTANCE_PROCEDURE.md](HARDWARE_ACCEPTANCE_PROCEDURE.md)。工具会拒绝把内置硬盘或仍连接网络的环境误记为通过。
