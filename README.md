# 凝然加密

**中文** | [English](README_EN.md)

凝然加密是一款面向 Windows x64 的本地文件保护程序。文件加密、解密、身份管理和设备核验均在本机完成，程序不会主动上传文件、密码、密匙或身份数据。

> 当前稳定版本：**6.1.10**。源码在分支 `release/v6.1.10`，Windows x64 安装包在 [GitHub Releases](https://github.com/2vkm2njr2y-droid/NingRan/releases/tag/v6.1.10) 提供。

## 主要功能

- 加密和解密文件或文件夹。
- 支持密码、密码加密匙文件、密码加物理设备三种保护方式。
- 解锁后可在程序内浏览加密文件树；常见文本、图片、音频和视频按需分段读取，不在磁盘留下明文。
- 内嵌安全媒体播放器支持文件列表、全屏、左右方向键快进或后退、单击或拖动进度条跳转，以及进度条悬停预览。
- 普通文件可按需导出或完整还原；图片支持缩放和滚动切换，音视频支持播放列表与结束后播放规则。
- 支持创建、备份和恢复私密身份。
- 支持分享公开身份，并通过大小写敏感的 7 位安全码确认联系人。
- 解锁前隐藏保护方式、原始名称、内部目录、发送者和设备信息。
- 同一 Windows 用户只打开一个主窗口；再次双击程序或关联文件时，由已有窗口接收新文件。
- 严格防护使用单独的管理员监控程序；它会保护主窗口、内嵌播放器、预览画面和监控程序自身。

## 常见文件类型

- `.nrenc`：凝然加密文件（6.1 起支持安全浏览和内置媒体读取）。
- `.nrkey`：程序生成的专用密匙文件。
- `.nrid`：加密的私密身份备份。
- `.nrpub`：可以分享的公开身份。

## 隐私与安全设计

- 加密文件可以自由改名，不影响正常解密。
- 原文件的完整路径不会写入加密文件。
- 保护方式、发送者身份、原文件名和内部目录等信息在成功解锁前不会显示。
- 物理设备的名称、型号、容量和原始编号不会以明文保存在加密文件中。
- 普通文件被用作密匙时只会被读取，不会被修改或转换。
- 6.1.0 使用可分段读取的新格式，不读取旧版 `.nrenc` 文件。

## 安全查看与媒体

解锁 `.nrenc` 后，程序默认只显示其中的加密文件树，不会自动导出明文。双击文本、图片、音频或视频会在程序内打开；同一文件夹内的媒体可按类型筛选。普通文件双击后由用户选择导出位置，也可选择“导出全部明文”。

安全查看时，凝然会独占锁定加密文件；若文件已经被其他程序占用，将拒绝打开。媒体预览直接在程序内部的小型播放画面中生成，只保留在内存中；如果两秒内无法取得画面，会明确提示“预览暂不可用”，不会无限等待。

也可以选择“严格防护”。监控程序会单独请求管理员确认；发现不在允许名单内的软件试图读取受保护内存时，会记录时间、访问程序、被访问组件和处理结果，立即停止当前操作并清理临时内容，再向用户提示。内置 Windows 安全软件和用户指定软件及其父子进程可以保留访问权限。日志不记录视频画面、文件内容、密码或密匙，并可由用户导出。

管理员权限不能阻止截图或具有更高权限的系统级访问，因此请只在确有需要时使用。

密码、密匙文件、私密身份备份和授权设备应分开保管。身份密码或必要的解锁材料遗失后，程序无法代为恢复。

## 安装

Windows x64 用户可从 [6.1.10 发布页](https://github.com/2vkm2njr2y-droid/NingRan/releases/tag/v6.1.10) 下载安装包。安装后如覆盖旧版本，请先完全关闭凝然加密再重新打开。

## 源码目录

```text
src/
  NingRan.Core/        加密、身份和设备相关的核心功能
  NingRan.Windows/     Windows 桌面程序
  NingRan.MediaPlayer/ 独立媒体播放器组件
  NingRan.StrictMonitor/ 严格防护监控程序
  NingRan.Setup.Core/  安装与系统接入的核心功能
  NingRan.Setup/       Windows 安装程序源码
```

## 编译和运行

需要：

- Windows x64
- .NET 10 SDK
- PowerShell 或 Windows 终端

下载源码后，在项目根目录运行：

```powershell
dotnet restore NingRan.sln --locked-mode
dotnet build NingRan.sln -c Release
dotnet run --project src/NingRan.Windows/NingRan.Windows.csproj -c Release
```

如需体验程序，可在编译完成后直接运行桌面项目；普通用户建议使用发布页中的安装包。
